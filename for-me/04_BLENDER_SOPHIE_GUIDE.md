# Blender Guide — Собачка Софи (game-ready)

## Главные принципы
1. **Game-ready ≠ красивая модель.** Порядок жёсткий: форма → топология → UV/материал → риг → тест анимации → и только потом остальное. Модель может выглядеть отлично и ужасно ломаться при ходьбе — проверяй риг на Idle/Walk сразу.
2. **Стилизация вместо реализма.** Софи — пушистая мальтезе, но real-time шерсть (particle fur) в игру не поедет. Решение: «клампы» шерсти моделятся как форма меша (chunky-стиль как в мультфильмах Pixar-lite / реф-арте заказчика) + матовый материал. Никаких particles/hair systems в экспорте.
3. **Low/mid-poly:** 5–15k трисов на собачку достаточно. Читаемый силуэт важнее деталей — эмоции ребёнок должен считывать с расстояния Sims-камеры.
4. **Крупные глаза** — отдельные меши-сферы (проще анимировать взгляд/моргание), нос, ошейник с жёлтым жетоном «Sophie» (узнаваемость по арту заказчика).

## Workflow c Claude
У тебя Blender подключён к Claude через MCP — используй так:
- **Blockout, пропсы, окружение, материалы, автоматизация** → промтами через Claude (bpy-скрипты). Площадка из рефа 5 (горка, качели, песочница) почти целиком генерится скриптами из примитивов + bevel + soft colors.
- **Сама Софи** → Claude делает базовый блокаут и риг-скелет, но форму, пропорции и топологию правишь руками — для детской игры character appeal решает всё, скрипт этого не даст.

## Скелет (простой квадрупед)
```
Root
└─ Spine (2 кости)
   ├─ Neck → Head (+ Ear.L/R, Jaw — опционально)
   ├─ FrontLeg.L (2–3 кости) / FrontLeg.R
   ├─ BackLeg.L / BackLeg.R
   └─ Tail (2–3 кости — хвост важен! виляние = главный эмоциональный сигнал)
```
Rigify quadruped можно, но для такого простого персонажа ручной риг чище для экспорта.

## Список анимаций MVP (10–12)
| Категория | Клипы |
|---|---|
| Движение | Idle, Walk, Run |
| Состояния | Sit, LookAround, Happy (виляние+подпрыг), Curious (наклон головы), Sad |
| Действия | Sniff, Bark, TailWag, Jump |

Готовых квадрупед-анимаций мало (Mixamo — только humanoid), так что анимировать самому. Хорошая новость: стилизованной собачке хватает 8–12 кадров ключей на цикл, а Claude может через MCP расставлять ключи скриптом по твоему описанию тайминга.

## Бруно и друзья
Бруно (высокий, тонкий, голубой, один глаз, зелёные кеды) технически проще Софи — почти капсульная форма, скелет двуногий, 4–5 анимаций: IdleSad (голова вниз, плечи внутрь), IdleOpen (финальное состояние), Walk, HandToChest, Wave. Арка «закрытая → открытая поза» — это буквально две idle-анимации + blend.

## Экспорт GLB (чеклист)
- Scale applied (Ctrl+A), масштаб реальный (~0.4 м высота Софи)
- Все анимации — именованные Actions, запушены в NLA
- Export glTF 2.0 → .glb, галочки: +Y Up, Apply Modifiers, Animation → NLA Tracks
- Текстуры — packed или одна атлас-текстура 1024px
- Проверка: перетащи .glb в https://gltf-viewer.donmccurdy.com — если там анимации играют, в движке тоже будут
