# Sophie & Friends — Алгоритм действий

## Что ты делаешь
Не игру целиком, а **vertical slice** (убедительный рабочий кусок): миссия Бруно, одна локация, собачка Софи, цепочка выбор → сцена → результат. Этого достаточно, чтобы заказчик увидел продукт.

## Порядок (6 фаз)

### Фаза 0 — Решение по стеку (сегодня, 30 мин)
Подтверди формат мока (см. вопрос от Claude в чате). Рекомендация: **веб-прототип (Three.js)** — быстрее всего, шарится ссылкой, Claude Code в вебе сильнее всего. Godot/Unity — если сразу нужен фундамент продакшн-игры.

### Фаза 1 — Game flow на сером (1–2 дня)
Claude Code, промты #1–#4 из `05_CLAUDE_CODE_PROMPTS.md`.
Капсула вместо собачки, кубы вместо мира. Цель: ходьба, камера, триггер ситуации, панель выбора, cinematic-камера, JSON-сценарий Бруно работает от начала до конца.
**Не открывай Blender, пока это не работает.**

### Фаза 2 — Софи в Blender (2–4 дня)
По гайду `04_BLENDER_SOPHIE_GUIDE.md`. Порядок жёсткий:
форма → топология → UV/материал → риг → тест Idle/Walk → остальные анимации → экспорт GLB.
Blender у тебя подключён к Claude через MCP — блокаут, пропсы и скрипты можно делать промтами прямо из чата.

### Фаза 3 — Сборка (1–2 дня)
GLB Софи + окружение заменяют серые болванки. Промты #5–#7.

### Фаза 4 — Сцены и полировка (1–2 дня)
Cinematic-сцены (реалтайм, не видео), звук, transitions, свет. Видео из Higgsfield — только для интро/финала, если останется время.

### Фаза 5 — Упаковка для заказчика
Ссылка на мок + короткий walkthrough-видос + Figma с флоу.

## Когда возвращаться к Claude (в чат)
1. **Сейчас** — ответить на вопросы по стеку/языку.
2. **После Фазы 1** — показать серый прототип: скорректирую промты под сцены Бруно (Scene 1–8), дам JSON всего сценария.
3. **Перед Фазой 2** — если хочешь, сгенерирую bpy-скрипты блокаута Софи и риг-структуру.
4. **После Фазы 3** — ревью UX/подачи, доки для передачи заказчику.
5. **Любой затык** — скрин + описание, разберём.
