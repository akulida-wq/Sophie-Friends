# Sophie & Friends — техническая документация для разработчиков

Vertical slice (играбельный мок) детской игры об эмоциональной устойчивости
для детей 4–9 лет. Веб-версия сделана как питч-прототип; ассеты (GLB),
контент (story JSON) и вся логика сцен спроектированы так, чтобы переехать
в Unity-продакшен с минимальными переделками.

Прод: https://sophie-friends.vercel.app
Репозиторий: https://github.com/akulida-wq/Sophie-Friends (ветка `main`,
каждый пуш автоматически деплоится на Vercel).

---

## 1. Стек

| Что | Версия | Зачем |
|---|---|---|
| TypeScript | ^7.0 (strict) | весь код игры |
| Three.js | ^0.185 | рендер, анимации (AnimationMixer), raycast |
| Vite | ^8.2 | dev-сервер (порт 5185), прод-сборка |
| Node.js | 24.x | сборка (никакого сервера в рантайме — сайт полностью статический) |
| Blender | 5.0.1 (CLI, headless) | конвейер ассетов: пересборка GLB, ремонт материалов, перекодирование медиа |
| Python 3 | системный | обработка звука (нарезка/фейды/нормализация WAV) внутри Blender-скриптов и отдельно |

Фреймворков (React и т.п.) нет — UI сделан на чистом DOM + CSS
(все стили в одном `<style>` внутри `index.html`). Состояние игры — свои
маленькие классы, никакого стейт-менеджера.

Зависимости продакшена — ровно одна: `three`. Dev: `typescript`, `vite`,
`@types/three`.

## 2. Как запустить

```bash
npm install
npm run dev        # http://localhost:5185
npm run build      # tsc + vite build -> dist/
npm run preview    # локальный просмотр прод-сборки
```

Хоткей в игре: **H** — скрыть/показать HUD (для чистых скриншотов).

Деплой: пуш в `main` → Vercel собирает `npm run build`, публикует `dist/`.
ВАЖНО: git-коммиты должны быть подписаны email'ом, привязанным к GitHub
(в репо задан `user.email = 315709941+akulida-wq@users.noreply.github.com`),
иначе Vercel блокирует деплой («could not associate the committer»).

## 4. Архитектура рантайма

- **Game** (`core/Game.ts`) — владеет WebGLRenderer, сценой, камерой и
  главным циклом (`renderer.setAnimationLoop`); системы подписываются через
  `game.addUpdatable((dt, elapsed) => ...)`. dt клампится 0.05с.
- **GameStateMachine** — состояния `EXPLORE / CINEMATIC / CHOICE`
  (+ пауза как DOM-оверлей). Управление у игрока только в EXPLORE.
- **SophieController** — тап по земле: raycast ТОЛЬКО в меш `ground`
  (внешняя земля `ground-outer` некликабельна — за двор не выйти);
  тап по интерактиву издалека → идём к нему → активация по прибытии
  (`goToInteract` → `onArrivedAtInteract`). К Бруно — всегда точка перед
  его лицом + разворот. Коллизии двора — `resolveYardCollisions`
  (набор кругов + прямоугольник дома + clamp по забору), при застревании
  >0.6с — мягкая остановка.
- **StoryEngine** — интерпретатор миссий из JSON. Типы сцен: `cinematic`,
  `choice`, `cinematic_choice`, `minigame`, `end_menu`. Контент (реплики,
  выборы, ветвления, тайминги видео) — ТОЛЬКО в JSON, в коде его нет.
  Ключевые механики: `generation`-счётчик обесценивает отложенные
  колбэки при выходе/рестарте; `simplify_after_misses` упрощает выбор
  после N промахов; `line_variants` — вариант реплики по предмету минигры;
  вопрос сцены озвучивается один раз, после redirect-выбора — только текст.
- **SafetyLayer** — «не наказываем»: при бездействии в свободной прогулке
  (30с, максимум 3 раза за сессию, только до знакомства с Бруно) мягкая
  подсказка + подсветка; N избегающих выборов подряд → мягкая ветка
  (`soft_branch_target` в JSON).
- **InteractionSystem** — интерактив = объект + `triggerRadius` +
  `onActivate`; ближайший в радиусе пульсирует эмиссивом (никаких миганий);
  `overrideActivate` — перехват во время минигры.
- **AudioSystem** (WebAudio, стартует после первого жеста):
  музыка лупом с громкостью по mood; фонтан — луп с громкостью от
  расстояния Софи (полная в 2 м, тишина за ~13 м, сглаживание
  `setTargetAtTime`); птицы — один луп на сессию: еле слышные «вспышки»
  по расписанию в прогулке, громче во время ролика; голос — HTMLAudio,
  `isVoicePlaying`-гейт не даёт репликам накладываться (страховка 12с от
  зависшего плейбека); `sfx(name)` из `/assets/sfx/`, отсутствие файла —
  тишина без ошибок.
- **VideoOverlay** — полноэкранный ролик (`object-fit: cover`), плавный
  вход из тьмы/уход в тьму, звук ролика приглушён (0.3), поверх — микс
  движка (`beginVideoAmbience`: своя мелодия, фонтан, птицы) и реплики по
  таймкодам (`cues` в JSON) с подписью-портретом. Ролик предзагружается
  fetch'ем в блоб после загрузки мира — не стримится при показе.
  Выход — только кнопкой ExitButton (z-index выше оверлея).
- **perf.ts (LITE-режим)** — на iOS/слабых CPU: pixelRatio ≤1.3 (вместо 2),
  тени выключены целиком, травы вдвое меньше. Детект: iPad/iPhone
  (включая iPadOS, который прикидывается MacIntel), `hardwareConcurrency<=4`,
  `deviceMemory<=4`.
- **LoadingScreen** — полоска прогресса по вехам загрузки
  (`loading.track(promise, weight)`: мир 6, Софи/Бруно по 1.5, друзья по 0.5)
  с плавной доводкой.

Бюджеты рендера: ~80 draw calls, ~2.4 млн треугольников на полном режиме.
Дорожки/забор/тротуар слиты в единые меши (1 draw call каждый), трава —
InstancedMesh (3600/1800 инстансов, детерминированный PRNG).

## 5. Конвейер ассетов (Meshy AI → Blender → GLB)

Все 3D-ассеты генерировались в **Meshy AI** (text-to-3D + авториг +
библиотека анимаций), затем пересобирались headless-скриптами Blender 5:

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b -P tools/blender/<script>.py
```

| Скрипт | Выход | Что делает |
|---|---|---|
| `build_sophie_meshy2.py` | `sophie_meshy2.glb` | Софи: родной квадрупед-риг Meshy (27 костей), их Walking + 10 авторских клипов, ошейник с жетоном |
| `build_bruno_meshy.py` | `bruno_meshy.glb` | Бруно: 12 анимаций Meshy → 15 игровых клипов (маппинг CLIP_MAP), пересобранный материал |
| `build_friends.py` | `friend_{yellow,pink,red}.glb` | друзья: клипы Idle/Look(/Chat), виниловый глянец |
| `build_environment2.py` | `environment2.glb` | ВЕСЬ мир одним GLB: дом, забор (меш-мердж), дорожки по сетке, фонтан, сад-клумба (тонированные копии ромашек), улица, соседние дома |
| `make_art_portraits.py` | `public/ui/portrait_*.png` | круглые портреты из 2D-артов (numpy-кроп с пером) |
| `encode_mp3.py` / `encode_video.py` | mp3 / mp4 | перекодирование медиа через Blender VSE (в системе нет ffmpeg) |
| `preview_friend_clips.py`, `preview_idles.py`, `sheet.py` | png | раскадровки клипов для ревью анимаций |

### Анимация персонажей — как это устроено

- Персонажи приходят из Meshy **уже с ригом и набором клипов** (glTF).
  Мы НЕ анимируем с нуля — отбираем/чистим клипы Meshy и, где нужно,
  делаем авторские поверх их рига (у Софи: галоп Run, Sit/Sad-холды,
  Sniff, TailWag и др. — кейфреймы ставятся скриптом через Python API).
- В движке: `AnimationMixer` + кроссфейды. У Софи walk/run переключаются
  контроллером по дистанции; HOLD-позы (Sit/Sad) — `LoopOnce` +
  `clampWhenFinished`. У друзей базовый Idle зациклен с рассинхроном
  (случайная фаза, timeScale 0.9–1.1), редкие фиджеты `playOnce` поверх
  с весовым блендом.
- Ориентация моделей задаётся параметром `yaw` при загрузке
  (`*.View.load(url, yaw)`), НЕ вращением rest-позы.

### Грабли конвейера (обязательно к прочтению перед правкой скриптов)

1. glTF-импорт даёт `rotation_mode='QUATERNION'` — `rotation_euler`
   МОЛЧА игнорируется. Всегда ставить `'XYZ'` перед поворотами.
2. `bpy.ops.transform_apply` в headless тихо фейлится — использовать
   data API (`mesh.transform(matrix)`).
3. Rest-позу риггованной модели НЕ вращать — ломает пространство
   анимационных кривых (модель «взлетает» при реэкспорте).
4. Blender 5: `Action.fcurves` больше нет — кривые в
   `action.layers → strips → channelbags`.
5. Клипы Meshy таскают scale-треки (сжимают скелет) и вертикаль Hips
   (топит персонажа в пол) — вырезать из клипов движения.
6. Коллапс-дециматизация рвёт плоские поверхности (плитка!) — для
   плоского только DISSOLVE(15°)+TRIANGULATE; для органики коллапс ок.
7. Материалы Meshy при экспорте ломаются (эмиссив-дубль, спекуляр×2,
   alpha BLEND → чёрный) — функция `clean_material` пересобирает их
   щадяще: родные текстуры остаются, base 2048, normal/MR 1024.
8. Сотни мелких размещений (плитки, секции забора) → `merged_from()`
   (bmesh) сливает в один меш = один draw call.
9. Текстуры окружения экспортируются JPEG q82 — режет GLB в разы.
10. Экшены при верификации подмешивают NLA-треки — глушить (mute).
11. Blender 5 видео-рендер: сначала `image_settings.media_type='VIDEO'`,
    только потом `file_format='FFMPEG'`.
12. Каждая пересборка GLB → бамп версии в `main.ts`
    (`ASSET_* = '...glb?v=N'`) — сбрасывает кэш браузера.

### Раскладка мира

Двор ±15.8 (забор), кликабельный газон ±16.6. Все дорожки живут на одной
сетке клеток: `cell(k) = 0.87 + k*1.06`. КРИТИЧНО: раскладка дорожек
продублирована в ДВУХ местах — `build_environment2.py` (кладёт плитку) и
`src/core/Environment.ts` (`TILE_CELLS` — там же трава не сеется и мел
рисует по плиткам). Менять раскладку = менять оба места синхронно.
Коллизии (`COLL_CIRCLES`/`COLL_RECTS`) и «проплешины» травы (`AVOID_*`)
тоже в `Environment.ts` — при перестановке объектов обновлять.

## 6. Контент-конвейер

- **Реплики** (текст) — только в `src/story/*.json`; id реплики =
  имя файла озвучки в `public/assets/voice/<id>.mp3`. Нет файла —
  показывается только текстовый пузырь, ошибок нет.
- **Голос Софи** — ElevenLabs, голос **Tilly** (Bright, Spirited),
  Eleven Multilingual v2, Speed 0.78 / Stability 65% / Similarity 85% /
  Style 25% / Speaker boost on. Полный список реплик — `VOICE_LINES.md`.
  У Бруно отдельный (более низкий) голос.
- **Музыка/эмбиент** — `public/audio/`: `music.mp3` (луп всей игры),
  `fountain.mp3`, `birds.mp3`, `memory_music.mp3` (мелодия ролика,
  вырезка с фейдами). Обработка звука — python (wave): нарезка лучшего
  окна по RMS, sin-фейды, one-pole lowpass, нормализация; кодирование
  mp3 — Blender VSE (`encode_mp3.py`).
- **Видео-воспоминание** — генерировалось в Higgsfield (Kling 3.0,
  image-to-video: стартовый кадр собран в Nano Banana Pro из скриншота
  игры + артов персонажей). В `memory.json` у экшена `video` есть
  `video_volume` и `cues` (реплики по таймкодам поверх ролика).
- **2D-арты персонажей** (портреты в диалогах) — сгенерированы отдельно,
  круглый кроп — `make_art_portraits.py`.

## 7. Правила безопасности (продукт, НЕ нарушать)

Из `CLAUDE.md`/`docs/01`: без резких звуков и миганий; никакого
fail-языка («wrong/failed/lose» запрещены — только мягкие редиректы);
без таймеров на выборах; максимум 3 карточки выбора, крупные (≥25%
высоты экрана), иконки важнее текста; пауза и выход доступны всегда
(ExitButton поверх любых оверлеев, включая видео); все ветки сходятся
к спокойной развязке. Подсветка интерактивов — медленный синус, не blink.

## 8. Известные ограничения / долги

- `environment2.glb` ~18.6 МБ и суммарно ~2.4 млн треугольников — на
  очень старых планшетах даже LITE-режим не даёт стабильных 60 fps.
  Резервы: меньше текстуры, агрессивнее дециматизация, LOD.
- Один большой чанк JS (варнинг Vite >500KB) — не критично для мока.
- Repo тяжёлый (~250 МБ с медиа) — история содержит старые бинарники;
  при желании чистится `git filter-repo`.
- Прогресс-бар загрузки — по вехам, не по байтам (большой GLB двигает
  полоску одним скачком ~50%).
- iOS iPadOS: `deviceMemory` недоступен — детект LITE по UA/тачам.

## 9. Портирование в Unity — что переносится как есть

- **GLB-модели и клипы** — импортируются напрямую (glTF-плагин или
  конверсия в FBX); имена клипов совпадают с теми, что дергает движок
  (`SophieView`/`BrunoView`/`FriendView` — готовая карта состояний).
- **story JSON** (`bruno.json`, `memory.json`, `props.json`) — схема
  описана в `docs/03_TECH_SPEC.md`; StoryEngine — референс-интерпретатор
  (~550 строк), переписывается на C# один в один.
- **Озвучка/музыка/sfx** — берутся как есть; конвенция «id реплики =
  имя файла» сохраняется.
- Раскладка мира — числа в `build_environment2.py` (метры).
