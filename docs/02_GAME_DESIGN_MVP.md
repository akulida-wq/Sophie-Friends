# Game Design — Vertical Slice (миссия Бруно)

## Scope MVP
- 1 локация: тихая игровая площадка / дворик (горка, песочница, качели — реф 5)
- Играбельный персонаж: Софи (собачка)
- 1 NPC с аркой: Бруно; 2–3 фоновых друга без диалогов
- 3–5 интерактивных объектов: мяч, кубики, мелки, дерево
- Сценарий: сцены 1–8 миссии Бруно из клиентского дока
- Длительность: 10–15 минут, без чтения (иконки + опциональная озвучка)

## Три слоя игры

### Слой 1 — Exploration (вид «как в Sims»)
Ребёнок управляет Софи: тап/клик по земле или джойстик → собачка идёт/бежит. Камера third-person, чуть сверху и сзади, плавно следует за Софи. Подойти к объекту/персонажу → объект мягко пульсирует (не мигает) → тап = взаимодействие.

### Слой 2 — Narrative (выбор «как в TWD»)
Триггер ситуации (подошла к Бруно / прошло событие) → управление отключается, камера мягко наезжает, появляется вопрос + 2–3 **крупные touch-карточки** с иконкой и минимальным текстом. Никакого таймера на выбор (в отличие от TWD!). Выбор эмоции — иконки-лица, выбор действия — иконки-сценки.

### Слой 3 — Cinematic (сцена «как в GTA»)
После выбора 5–15 секунд без управления: cinematic-камера (2–3 пресета: wide / close-up / over-shoulder) + анимации персонажей + реплика Софи (озвучка/пузырь) + мягкий музыкальный сдвиг. Затем камера возвращается к Софи, управление включается.
Реалтайм-сцены, не видео. Видео (Higgsfield) — только интро и финал-награда.

## State machine состояния Бруно
`withdrawn → noticed → named → accepted → trying → wobble → connected`
Каждый шаг = видимое изменение позы/анимации: опущенная голова и сжатые плечи в начале → открытая поза, мягкая улыбка в конце. Цветовая температура сцены: холоднее в начале, теплеет к развязке.

## UI-правила (детские, 4–9)
- Карточки выбора: min ~25% высоты экрана, иконка > текста, до 3 штук
- Один основной интерактив на экран, нет HUD-мусора
- Никаких дропдаунов, мелкого текста, «SaaS-интерфейса»
- Подсветка интерактива — мягкая пульсация glow, никогда не blink
- Pause/Exit — всегда в верхнем углу, иконка «домик/пауза», без confirm-диалогов со стеной текста
- Фидбек всегда тёплый: анимация + звук + слова Софи; ни одного красного крестика

## Sophie-интервенции (системная логика, не скрипт)
- Бездействие >10 сек → Софи подходит, подсвечивает один объект: «A little step is enough»
- 2-й избегающий выбор подряд → укороченная мягкая ветка
- Повторная ошибка распознавания эмоции → варианты упрощаются до 2

## Definition of Done мока
- Проходится за 10–15 минут без чтения
- Все ветки завершаются спокойно, fail-языка нет нигде
- Арка Бруно читается чисто визуально (поза/цвет/музыка)
- Работает на планшете (touch) — целевое устройство ребёнка
